# Contributing

Work happens in small, reviewable steps:

1. **Start from an issue.** Bugs and features use the templates; experiments state a
   hypothesis and a decision rule before any run.
2. **Branch and open a pull request.** One idea per PR, linked to its issue.
3. **Show evidence.** Tests for behaviour changes; result files for any claimed number.
4. **Merge when CI is green.** Releases are tagged with a CHANGELOG entry.

Bug reports and ideas are welcome as issues.
